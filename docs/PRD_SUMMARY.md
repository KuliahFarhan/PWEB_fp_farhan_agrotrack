# PRD Summary

AgroTrack is a native PHP web application for agricultural land monitoring, planting season management, production cost tracking, harvest tracking, profit analysis, and reporting.

Core roles:
- Guest: landing page, login, register, forgot password.
- Petani: dashboard, lahan, peta lahan, musim tanam, biaya produksi, hasil panen, analisis, laporan, profil.
- Admin: dashboard, users, master tanaman, monitoring lahan, laporan global.

Core technologies:
- Native PHP, MySQL, HTML, CSS, JavaScript.
- Tailwind CSS or Bootstrap.
- Leaflet and Leaflet Draw.
- Chart.js.
