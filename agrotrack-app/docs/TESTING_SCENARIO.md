# Testing Scenario

Planned demo flow:

1. Guest opens the landing page.
2. Guest registers as petani.
3. Petani logs in and opens the dashboard.
4. Petani creates lahan.
5. Petani opens peta lahan and saves marker/polygon.
6. Petani creates musim tanam and sees estimasi panen.
7. Petani records biaya produksi and hasil panen.
8. Petani opens analisis and laporan.
9. Admin logs in.
10. Admin checks dashboard, users, tanaman, monitoring lahan, and laporan.

Detailed test cases will be added after features are implemented.
