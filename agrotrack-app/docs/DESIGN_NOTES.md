# Design Notes

The `figma-export` folder is only a visual reference. Figma-exported HTML uses many fixed and absolute-positioned Tailwind classes, so final pages should be rebuilt with responsive native PHP views and reusable components.

Visual direction:
- Primary color: dark agricultural green / teal.
- Accent color: yellow for highlights and CTA emphasis.
- Neutral colors: white, gray, slate.
- Use card-based dashboards, clean forms, simple tables, confirmation modals, alerts, and toasts.
- Recreate small UI elements with Tailwind CSS or Bootstrap instead of copying Figma elements directly.
